# 站点分区规划（保存点）

> 在实现可点击标语导航之前的设计共识，便于回溯与迭代。

## 三区含义

| 入口（标语） | 中文名 | 内容 |
|-------------|--------|------|
| **Take root** | 学术区 | 技术基础、数学原理、Lesson 类文章 |
| **sprout,and then** | 成长区 | 工作内容、旅游与日常 |
| **grow wildly** | 技术探索区 | 工作之外学习的前沿技术 |

## 导航形式（倾向）

- **主入口**：首页三色标语分段可点击跳转，保留隐喻与品牌。
- **辅助**：悬停或标语下方一行中文路标（学术 · 成长 · 探索），不设右侧大标题栏。
- **路由（待定）**：如 `/root`、`/sprout`、`/grow`（或 `/learn`、`/life`、`/explore`）。

## 内容模型（待定）

- 三个 content collection，或单一 `blog` + frontmatter `zone: root | sprout | grow`。
